# CINÉMA — مكتبة الأفلام والمسلسلات

مكتبة منظمة لأشهر الأفلام والمسلسلات من 2013 إلى 2025، في صفحة واحدة بدون أي خادم أو أدوات بناء. واجهة عربية (RTL) بثيم داكن وألوان حمراء.

## المميزات

- عرض الشبكة افتراضيًا، مع خيار عرض الصفوف حسب السنة.
- تبديل بين الأفلام والمسلسلات، واختيار سنة محددة أو كل السنوات.
- ترتيب حسب أصوات IMDb أو التقييم أو تاريخ العرض، تصاعديًا أو تنازليًا.
- تصفية بالأنواع (يمكن اختيار أكثر من نوع) وبحد أدنى للتقييم (7+ أو 8+ أو 9+) وببحث نصي.
- نافذة تفاصيل فيها قصة العمل بدون حرق، وأعمال مشابهة، ورابط مباشر لصفحته على IMDb.
- زر «اختر لي» لاختيار عمل عشوائي من النتائج الحالية.
- قائمة مفضلة محفوظة في المتصفح.
- حالة الفلاتر محفوظة في رابط الصفحة، فيمكن مشاركة أي عرض.
- تنزيل كل البوسترات في ملف ZIP.
- الضغط على الشعار يعيد الصفحة إلى حالتها الأصلية.

## التشغيل محليًا

افتح `index.html` في أي متصفح حديث. لا يوجد تثبيت ولا بناء.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع هذه الملفات إليه.
2. من **Settings ← Pages**، اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم **Save**.
4. بعد دقائق تظهر الصفحة على `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.

الملف `.nojekyll` موجود لتجنب معالجة Jekyll للصفحة.

## مصادر البيانات

بيانات العناوين والتقييمات وعدد الأصوات مضمّنة داخل `index.html`. أما البوسترات وقصص الأعمال وروابط IMDb فتُجلب وقت التشغيل من خدمات خارجية مجانية، ولهذا يلزم اتصال بالإنترنت:

- Cinemeta (Stremio) لأرقام IMDb والبوسترات وقصص الأفلام.
- TVmaze لقصص المسلسلات وكاحتياطي للبوسترات.
- Wikipedia وiTunes وفهرس بوسترات TMDb كمصادر احتياطية.
- Google Translate لترجمة القصة إلى العربية.

النتائج تُحفظ في `localStorage` لتسريع الزيارات التالية. إذا توقفت إحدى هذه الخدمات أو غيّرت شكل ردودها فقد تظهر بعض الأعمال بلا بوستر أو قصة. زر «إعادة محاولة البوسترات» يعيد المحاولة.
